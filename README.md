# Social Work Learning

## About This Project
This repository is created to collect and organize educational resources for social work students.

## Objectives
- Share social work learning materials.
- Understand social work theories and methods.
- Support academic research and assignments.
- Learn about community development.

## Topics Covered
- Social Case Work
- Social Group Work
- Community Organization
- Social Welfare Administration
- Social Work Research
- Medical and Psychiatric Social Work

## Project Status
This is a beginner learning project. Educational resources will be added and improved over time.

## Purpose
To support students in learning social work concepts and developing academic knowledge.
